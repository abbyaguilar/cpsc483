# CPSC 483 — Introduction to Machine Learning

Coursework from **CPSC 483: Introduction to Machine Learning** completed as part of my B.S. in Computer Science at California State University, Fullerton.

This repository is intentionally presented as **academic coursework**. It contains instructional material alongside my completed exercises and is useful as evidence of the concepts and tools I worked with during the course rather than as a standalone production ML project.

## Topics Represented

- Probability and statistics foundations
- NumPy and pandas
- Data visualization with matplotlib
- Linear regression
- Residual analysis and least-squares fitting
- Gradient descent
- Basis-function expansion
- Polynomial regression
- Introductory neural networks
- TensorFlow / Keras
- Model training and evaluation

## Notebooks

### `lab0.ipynb` — MNIST Neural Network

An introductory TensorFlow/Keras exercise using the MNIST handwritten-digit dataset.

Concepts include:

- Image normalization
- Dense neural-network architecture
- ReLU and softmax activations
- Categorical targets
- Training and test evaluation
- GPU-backed Colab execution

### `lab2_linear_regression.ipynb` — Linear Regression

A longer instructional lab covering the mathematical and practical foundations of regression.

Topics include:

- House-price regression examples
- Residual analysis
- Closed-form least squares
- Gradient descent
- Basis-function expansion
- Polynomial fitting
- Cosine fitting

### `student.ipynb` — Probability & Statistics Foundations

Foundational Python exercises covering:

- Probability
- Permutations and combinations
- Random-number generation and simulation
- Histograms and exploratory visualization
- Iris dataset exploration
